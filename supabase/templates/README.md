# E-mails de autenticação — CRM PLUS

Templates oficiais usados como fonte de verdade para o Supabase Auth.

## Assuntos

- Confirmação: `Confirme seu e-mail | CRM PLUS`
- Recuperação: `Redefina sua senha | CRM PLUS`
- Convite: `Convite para acessar o CRM PLUS`
- Magic Link: `Seu acesso ao CRM PLUS`
- Alteração de e-mail: `Confirme seu novo e-mail | CRM PLUS`
- Reautenticação: `Seu código de segurança | CRM PLUS`

## Remetente recomendado

`CRM PLUS <nao-responda@auth.crmplus.store>`

A produção deve usar SMTP próprio. O remetente padrão do Supabase não deve ser usado em produção.
