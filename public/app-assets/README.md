# Assets dos aplicativos

Esta pasta é reservada para os arquivos visuais dos aplicativos.

## Formatos aceitos

- Ícone: `icon.svg`, `icon.png`, `icon.jpg` ou `icon.jpeg`
- Capa: `cover.jpg`, `cover.png`, `cover.svg` ou `cover.jpeg`
- Card: `card.jpg`, `card.png`, `card.svg` ou `card.jpeg`

O front-end tenta os formatos automaticamente. Para evitar ambiguidade, mantenha apenas um formato por tipo de asset em cada pasta.

## Pastas

- `zeus/`
- `artemis/`
- `athena-pesquisa/`
- `kronos/`
- `athena-orcamentos/`

Zeus e Artemis usam `cover` e `card` na Store. Todos os aplicativos usam `icon` dentro do próprio app.
